# 🎬 MovieBox

A personal movie and TV show watchlist app to discover titles, track what you want to watch, and save ratings and reviews.

### ✨ Features
- 🔍 Search movies and TV shows
- 📋 Manage your personal watchlist
- ✅ Track watched titles
- ⭐ Add ratings and reviews
- 🔐 User authentication

### 🛠️ Tech Stack
**Frontend:** React.js, Vite  
**Backend:** Python, FastAPI  
**Database:** MySQL, SQLAlchemy  
**API:** OMDb API  
**Deployment:** Render

### 🚀 Live Demo
- **Frontend:** [MovieBox](https://moviebox-frontend.onrender.com)

### 💻 Run Locally

```bash
# Clone the repository
git clone https://github.com/aaryanjain16/MovieBox.git
cd MovieBox

# Backend
pip install -r requirements.txt
uvicorn Film:app --reload

# Frontend (in a separate terminal)
cd frontend
npm install
npm run dev
```

Configure the required environment variables before starting the application.
